💧 Hydration Coach Chatbot

A Flask-based AI chatbot that acts as a Virtual Hydration Coach, helping users stay properly hydrated by answering hydration-related questions using Google's Gemini model.

🚀 Features
💬 Chat-based interface for hydration guidance
🤖 Powered by Gemini AI (gemini-flash-latest)
🎯 Restricts responses to hydration-related queries
⚡ Fast and lightweight Flask backend
🔐 Secure API key handling using environment variables
🛠️ Tech Stack
Backend: Python, Flask
AI Model: Google Generative AI (Gemini)
Frontend: HTML (via Flask templates)
Environment Management: dotenv (.env)
